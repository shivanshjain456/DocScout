# Getting Support for DocScout

Thank you for using DocScout. We want to ensure you have the resources and assistance needed to run, deploy, and contribute to the platform effectively.

---

## 1. Documentation Resources

Before opening an issue, check the comprehensive documentation available in the repository:

- **[README.md](README.md):** Quickstart, architecture overview, benchmarks, and common commands.
- **[SPEC.md](SPEC.md):** Authoritative system specification and requirement register.
- **[Architecture & Data Model](docs/architecture/ARCHITECTURE.md):** Components, PostgreSQL schema, 53 migrations, and 91 ADRs.
- **[Operational Integrations Guide](docs/OPERATIONAL_INTEGRATIONS_GUIDE.md):** Auth0 OIDC, Brevo transactional alerts, and OCR.space fallback.
- **[Quality Bar](docs/QUALITY_BAR.md):** Definition of done, test suites, and regression gates.
- **[Evaluation Protocol](docs/eval/EVAL_PROTOCOL.md):** Gold set v2.0.0, scorers, and judge calibration.

## 2. Where to Get Help

### Technical Questions & Discussions
For general questions about system design, local setup, or API usage:
- Open a question on GitHub using [GitHub Discussions](https://github.com/shivanshjain456/DocScout/discussions) (if enabled) or consult the [FAQ section in README.md](README.md#faq).
- Check existing closed issues and pull requests to see if your question has been addressed previously.

### Reporting Bugs & Regressions
If you encounter a bug, crash, or unexpected behavior:
- Submit a structured report using our [Bug Report Form](.github/ISSUE_TEMPLATE/bug_report.yml).
- Include exact steps to reproduce, terminal outputs, and environment details.

### Requesting Features
To propose an architectural enhancement or new compliance feature:
- Submit a proposal using our [Feature Request Form](.github/ISSUE_TEMPLATE/feature_request.yml).
- Note which of the 10 Architectural Pillars your proposal aligns with.

### Reporting Regulatory Data Discrepancies
If you identify an issue with an RBI or SEBI circular's text extraction, character offset, or metadata:
- Submit a report using our [Regulatory Data Discrepancy Form](.github/ISSUE_TEMPLATE/regulatory_data_issue.yml).

---

## 3. Security Inquiries

Do **NOT** report security vulnerabilities through public GitHub issues.
Please refer to our [Security Policy](SECURITY.md) for confidential disclosure instructions.

---

## 4. Accessibility Assistance

If you experience accessibility barriers while using DocScout's web console or documentation, review our [Accessibility Statement](ACCESSIBILITY.md) or contact compliance-alerts@docscout.gov.in.
