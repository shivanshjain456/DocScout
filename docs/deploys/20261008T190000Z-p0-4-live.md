## Defects found live (all fixed in-tree, none weakened)

- `app/evals/runner.py` crashed writing `results.json` on Windows
  (`UnicodeEncodeError` on ₹ U+20B9: `write_text()` defaults to cp1252).
  Fixed with explicit `encoding="utf-8"` on every text read/write in `app/`
  and `scripts/` handling corpus-derived content (runner, gate, pipeline,
  source, config, migrate, bench, audit, mutation_report,
  verify_corpus_fetch) plus the same one-token fix in the test files that
  read JSON artifacts (coherence, rescope, dependency_audit, gate, ingest,
  conftest). Zero behavior change on Linux (utf-8 is already the default).
- The crashed run left `evals/reports/20261008T185932Z/results.json` (0
  bytes), which correctly tripped `test_rescope.py`'s committed-report guard.
  Deleted (gitignored remnant, no evidence value); guard green again. The
  gates catching a broken artifact mid-session is the system working.
